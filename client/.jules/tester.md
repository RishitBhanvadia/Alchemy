## 2025-02-21 - Added test suite for authStore
**Gap:** The critical authentication flow via `authStore.js` lacked any test coverage, leaving the application vulnerable to subtle regressions in login, logout, and profile fetch functionality.
**Learning:** Zustand stores often have implicit or internal state (like fetching user profile logic inside `init()`) and event listeners (like `onAuthStateChange`). Using `vi.mock` for external dependencies (Supabase) and specifically testing state mutations and console errors covers both the happy paths and exception handling. Setting `window.location.href` temporarily to mock redirects when `SIGNED_OUT` occurs is also critical for testing auth flows.
**Pattern:** To effectively test Zustand stores integrating with third-party auth services, deeply mock the service client methods (`getSession`, `onAuthStateChange`, `signOut`, `from()`), assert on store state after async actions, and selectively override DOM properties (`window.location`) when necessary.
