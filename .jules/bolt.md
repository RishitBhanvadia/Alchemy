## 2024-03-04 - Lazy load heavy 3D components for faster initial load
**Learning:** Massive 3D rendering libraries and components (like `@react-three/fiber`, `@react-three/drei`, `CanvasContainer`, and `FloatingMolecule`) significantly impact the initial JS bundle payload. In this architecture, rendering them eagerly on entry pages like `Landing` or `lab` blocks First Contentful Paint. Furthermore, lazy-loading named exports from these heavy libraries (like `OrbitControls` from `@react-three/drei`) requires a promise chain (`lazy(() => import('@react-three/drei').then(module => ({ default: module.OrbitControls })))`) to map the export to the default property, as `React.lazy` expects default exports.
**Action:** Always wrap heavy 3D modules with `React.lazy` and a `Suspense` fallback in route components to prevent huge initial load bottlenecks. Use promise chaining mapping to default for lazy-loading named exports from large libraries.
