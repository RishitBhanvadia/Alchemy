## 2024-05-18 - Lazy Load Heavy Components in Route
**Learning:** Code splitting route components by lazy loading heavy visual components (like 3D viewers, large charts, modale, etc) combined with `Suspense` significantly reduces the initial main bundle payload and improves time-to-interactive.
**Action:** When working on performance, actively search for heavy sub-components that aren't critical to the immediate initial render but contribute significantly to the bundle (like `AiTutorPanel` and `ResultModal` in `Lab3D.jsx`) and code-split them using `React.lazy()` wrapped in `<Suspense>`. However, avoid including generic React performance tips in journals unless they provide codebase-specific architectural learnings. Ensure PRs for performance also satisfy the specific code-level documentation requests of the user (e.g. inline code comments).
