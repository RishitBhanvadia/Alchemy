## 2024-03-11 - Optimize CursorFollower performance by replacing useState with useRef
**Learning:** React state (`useState`) is meant for data that drives rendering. High-frequency events like `mousemove` cause rapid state updates when used with `useState`, forcing React to continuously re-render the component. In our case, the `CursorFollower` component was re-rendering on every mouse move just to update its position, which can cause jank, lag, and poor overall app performance.
**Action:** Always use a combination of `useRef` and direct DOM manipulation for tracking and visually representing high-frequency positional events (like custom cursors or scroll tracking). By attaching `useRef` to the cursor elements and directly updating their `style.transform` properties inside the `mousemove` handler, we completely bypass React's render cycle, achieving a buttery-smooth custom cursor with practically zero impact on React's rendering performance.
