## 2026-03-14 - Replace useMemo with lazy useState for randomized Three.js particle properties
**Learning:** Using `useMemo` with impure functions like `Math.random()` to generate randomized particle values inside React components causes ESLint `react-hooks/purity` errors. However, blindly replacing `useMemo` with a lazy `useState` can break reactivity if the dependency array previously relied on dynamic props (like particle count).
**Action:** Always verify if a dependency array in `useMemo` contains variables that might change during the component lifecycle. If they do, replacing it with lazy `useState` (which only runs on the initial mount) will introduce functional regressions. In such cases, the `useMemo` may need to be restructured or the ESLint rule suppressed correctly instead of changing the hook type.
