## 2025-05-23 - Proper Modal Keyboard Accessibility and Escape Key Handling
**Learning:** Adding an `onKeyDown` handler to stop propagation on an inner modal container breaks outer overlay key listeners. Attempting to listen for the `Escape` key on the outer overlay `div` to close the modal will fail if the inner dialog explicitly stops event propagation (which is often done to satisfy `jsx-a11y/click-events-have-key-events` for the background click-to-close behavior).
**Action:** Attach the `Escape` key close listener to the global `window` object inside a `useEffect` hook instead of relying on React's event bubbling up to the overlay wrapper. Additionally, ensure the overlay has `role="presentation"` and the inner modal container has `role="dialog"` and `aria-modal="true"`.
