## 2024-05-24 - Missing ARIA Labels on Icon-Only Navigation
**Learning:** Icon-only navigation links (like those in the sidebar using FontAwesome icons) are completely inaccessible to screen readers without explicit `aria-label`s. In addition, users lacking domain knowledge or context might not understand what an icon represents, making a `title` attribute for tooltips essential for general usability. Internal buttons inside interactive links like `NavLink` can also cause double-focusing issues with screen readers if not properly managed (e.g., via `tabIndex={-1}`).
**Action:** When creating icon-only buttons or links, always add an `aria-label` for screen readers and a `title` for visual tooltips. If wrapping a button in a focusable element like `NavLink`, add `tabIndex={-1}` to the inner button to maintain a clean tab order.
