## 2024-06-07 - React rendering stability and CI immutability crashes fixed
**Bug:** Mutating R3F geometry configurations out of standard patterns generated ESLint immutability crashes (`react-hooks/immutability`), and components with early returns placed above `useEffect` triggers fatal hook crashes under certain viewport conditions. `SuccessCelebration` generated infinite cascade errors by synchronously executing setState on load.
**Root Cause:** Mutating `gl.domElement.style.cursor` in R3F causes lint cascades. React component `CursorFollower` placed early returns before rendering its `useEffect`, a classic hooks-order violation. State assignments without `requestAnimationFrame` bounds leak memory. Testing scripts importing `server/server.js` hung and timed out due to Express starting automatically.
**Learning:** React Component constraints strictly require early returns to exist strictly beneath hook initialisations, and updating specific properties should leverage standard browser document interactions where R3F encapsulation causes React-lint panics. Always sanitize dependency imports to clean build pipelines. Backend tests that require Express servers need `if (require.main === module)` bounds to prevent blocking execution.
