## 2025-02-28 - Duplicate Variable Declarations Break Vite/esbuild Compilation
**Bug:** The Vite development server was failing to start (`Command "dev" not found` or similar Vite crash) due to an esbuild compilation error: `The symbol "clicking" has already been declared`.
**Root Cause:** In `client/src/components/CursorFollower.jsx`, variables like `clicking` and `hovering` were declared twice using `const`. Furthermore, there was an early return before a React hook. Vite's default esbuild bundler is strict and refuses to compile files with duplicate constant declarations, entirely halting the build process.
**Learning:** Always check for duplicate variable definitions (especially state definitions resulting from copy-paste) and always ensure early returns occur *after* all hooks (`useEffect`, etc.) in React to avoid both esbuild crashes and React Hooks lint errors. Run `npm run lint` and verify the development server starts with `npm start` after making React hook modifications.
