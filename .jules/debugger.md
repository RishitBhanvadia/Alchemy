## 2024-05-24 - React Functional State Updater Side-Effects & Event Target Null Reference
**Bug:** The application crashed when moving the custom cursor over non-element nodes due to missing null checks in `CursorFollower.jsx`, and a `useEffect` interval loop in `titration.jsx` had side-effects (DOM manipulation) inside the state updater callback.
**Root Cause:** In `CursorFollower.jsx`, `e.target` could be a text node or `null` resulting in a `TypeError: Cannot read property 'toLowerCase' of undefined`. In `titration.jsx`, calling `setAcid` inside `setCount(prev => ...)` breaks React's purity rules, potentially causing double-invocation issues and hard-to-track bugs.
**Learning:** Always use optional chaining (`?.`) when accessing properties on `e.target` in global mouse events, as the target may not be an element node. Never place side-effects (like dispatching other state updates) inside functional state updater callbacks; instead, extract them to a separate `useEffect` that depends on the state variable.
