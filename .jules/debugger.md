## 2024-05-20 - Fix Node 18 CI build issues
**Bug:** The Github CI is failing across two suites: the `build` suite due to an optional dependency bug in `npm` resolving `@tailwindcss/oxide` on Node 18 (and hanging indefinitely on server test), and the `test` suite which is triggering a host of eslint warnings/errors around `<a>` tags acting as buttons, and missing accessible roles for non-abstract React roles.
**Root Cause:** The `build` workflows specify `node-version: 18` or `18.x`, but Tailwind v4's optional dependencies conflict heavily with npm on Node 18. The server build hangs because requiring `server.js` starts the Express server which never exits. Eslint fails the job because `npm run lint` exits with a code `1` due to errors in auth components, such as anchor elements without valid `href`s acting as buttons, and unused imports.
**Learning:** To unblock CI immediately in this repo, it is critical to upgrade `.github/workflows` to Node `20` everywhere, to wrap server CI startups with `setTimeout(() => process.exit(0), 1000)` to prevent hangs, and to address strict accessibility rules regarding anchor elements (`jsx-a11y/anchor-is-valid`) by converting them to `<button>` with appropriate styling.
