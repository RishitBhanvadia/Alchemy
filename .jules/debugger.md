## 2024-05-11 - Fix Vite Build Error and Performance Issue in CursorFollower
**Bug:** The Vite build failed with `ERROR: The symbol "clicking" has already been declared` due to duplicate state variables in `CursorFollower.jsx`. Additionally, there was severe performance degradation due to updating component state on every `mousemove` event, and a React hook rule violation by calling an early return before `useEffect`.
**Root Cause:** State variables (`clicking`, `hovering`) were redeclared twice in the component scope. The cursor tracked position by updating React state (`useState`) during high-frequency `mousemove` events, triggering excessive full component re-renders. A conditional early return (`if (isTouchDevice) return null;`) was placed before a hook (`useEffect`).
**Learning:** For tracking high-frequency events like cursor movements, use `useRef` to directly manipulate DOM element styles (e.g., `element.style.left`) instead of `useState` to bypass the React rendering cycle and improve performance. Additionally, always place conditional component returns after all React hook declarations to comply with rules of hooks, and be cautious of duplicate variable declarations to ensure esbuild works properly during Vite builds.
