## 2024-05-15 - Fix duplicate variables and Rules of Hooks violation in CursorFollower
**Bug:** Duplicate variable declarations (`clicking`, `hovering`) in `CursorFollower.jsx` caused esbuild to fail. Additionally, `useState` hooks were declared after an early return (`if (isTouchDevice) return null;`), violating React's Rules of Hooks. The initial implementation also suffered from performance issues by using `useState` to track `mousemove` events, causing full component re-renders on every pixel moved.
**Root Cause:** A copy-paste error likely resulted in the duplicate variable declarations. The hooks violation occurred because conditional returns were placed before hook initializations. The performance issue was due to attaching state updates directly to high-frequency DOM events.
**Learning:** Always initialize all React hooks at the top level of a component before any conditional early returns. Avoid using `useState` for high-frequency events like `mousemove` or `scroll`; instead, use `useRef` to directly manipulate DOM element styles to completely bypass the React render cycle and prevent severe performance degradation. Always test for null or undefined properties on `e.target` when inspecting generic DOM events.
