## 2025-02-13 - [Fix Math Rounding Logic and Scope Shadowing Error in calculateResult]
**Bug:** The server crashed with a `TypeError: error is not a function` when handling 0% inputs due to overlapping variable scope, and the reaction logic incorrectly distributed remainder percentage points to chemicals with a 0% input.
**Root Cause:** A destructured `error` variable from a Supabase call shadowed a globally imported utility function named `error`. Additionally, the formula `nc = 100 - na - nb - ni` forced the remainder of percentage rounding onto `chem_c` blindly, even if `chem_c` was originally `0`.
**Learning:** In Node.js controllers, avoid shadowing globally imported helper functions with locally destructured variables in the same block. For math rounding constraints summing to 100%, distribute the discrepancy to the largest *non-zero* original value to prevent zero inputs from mutating into non-zero inputs.
## 2025-02-13 - [Fix CI Build Failures: Linter Errors and Missing Environment Variables]
**Bug:** The GitHub Actions CI pipeline failed during both the `build-server` and `test (18.x)` steps. The server failed its startup script test because the `supabaseClient.js` initialization threw an error when expected environment variables were missing, before the custom `validateEnv.js` script could run and print its expected "STARTUP FAILED" message. The client failed due to multiple strict ESLint enforcement errors (e.g., unused variables, missing display names, accessibility attributes, unescaped entities).
**Root Cause:** In the server, `createClient` was initialized with potentially `undefined` credentials from `process.env`. In the client, the linter rules were strictly set to fail on warnings, meaning minor development oversights broke the build.
**Learning:** For continuous integration pipelines verifying server startup manually (e.g., using `node -e`), always provide fallback placeholder strings for essential third-party clients (like Supabase) to prevent premature crashes before the primary test logic evaluates. In the frontend, treat lint warnings as critical blockers; when fixing `jsx-a11y/anchor-is-valid` by changing anchors to buttons, explicitly specify `type="button"` to avoid accidental form submissions.
