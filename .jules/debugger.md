## 2024-05-19 - Fix React setInterval Memory Leak and Supabase Client Crash
**Bug:** The app crashed on initialization without Supabase environment variables, and the titration timer consumed excess resources and caused memory leaks by continuously creating and destroying intervals.
**Root Cause:** `createClient` throws an error if URL/keys are evaluated as "undefined" strings during Vite build/startup without fallbacks. In the React timer, `count` was mutated inside `setInterval` while also being listed as a dependency of the `useEffect` that created the interval, causing a continuous unmount/remount cycle. Additionally, cleanup side effects were incorrectly placed inside the `setCount` functional updater.
**Learning:** Provide explicit string fallbacks for Supabase environment variables to prevent startup crashes. For React intervals, use functional state updaters (`prevCount => prevCount + 1`) to avoid adding state dependencies to the interval's `useEffect`, and place side-effects (like clearing the interval or updating other state variables) in a separate `useEffect` that responds to the changing state.
