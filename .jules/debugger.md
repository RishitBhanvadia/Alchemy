## 2024-05-20 - Fix React Rules of Hooks Violation and Build Error
**Bug:** Duplicate `useState` declarations and an early return before a hook caused build failures and potential React runtime crashes. Additionally, an invalid CSS `@import` order broke the Tailwind/Vite build process.
**Root Cause:** Two blocks of `useState` declarations for the identical states (`clicking`, `hovering`) were added. Between these duplicate blocks, an early return statement `if (isTouchDevice) return null;` conditionally blocked execution of the `useEffect` hook. Separately, an `@import url` font rule in `index.css` was incorrectly positioned after the `@import "tailwindcss"` rule causing esbuild to throw an error.
**Learning:** Always verify hook order in React to ensure the number of hook calls remains deterministic across renders. Early returns must be placed *after* all hook declarations. When using Tailwind CSS v4 in Vite, ensure native `@import` statements (like Google Fonts) appear before the `@import "tailwindcss"` directive to prevent esbuild errors during the build step.
