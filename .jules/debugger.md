## 2025-02-23 - Fix accessibility and linting errors in Auth components
**Bug:** The application had several accessibility and linting errors causing build warnings/failures, specifically `jsx-a11y/anchor-is-valid` and `jsx-a11y/aria-role` related to `<a>` tags used as buttons and a prop named `role` passed to custom React components conflicting with standard ARIA role attributes.
**Root Cause:** Using `href="#"` on anchor tags acting as interactive placeholders rather than navigation triggers causes screen readers to misinterpret them. Additionally, passing `role="student"` to a custom `RoleCard` component conflicts with ESLint's ARIA role checking since `role` is a reserved native DOM attribute expected to have standard values like `button`, `dialog`, etc.
**Learning:** For non-navigating placeholder links (like 'Forgot password?' or 'Terms of Service'), always use `<button type="button">` instead of `<a href="#">`. To avoid `jsx-a11y/aria-role` lint errors with custom components, use alternative prop names like `roleType` instead of `role`. Always remove unused imports to keep code clean.
