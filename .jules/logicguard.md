## 2024-05-24 - Regime Classifier Early Return Bug
**Bug:** The `classifyRegime` function blindly returns an acid-base regime ('ACID_DOMINANT', 'BASE_DOMINANT', or 'NEUTRAL') if `acidBaseSum > 0`, ignoring catalyst and indicator dominance unless `acidBaseSum === 0`.
**Root Cause:** The `if (acidBaseSum > 0)` block returns early, completely shadowing the checks for `CATALYST_DOMINANT` and `INDICATOR_DOMINANT` even when the catalyst or indicator is clearly the dominant chemical (e.g., C=90, A=10). The condition for catalyst/indicator relies on `acidBaseSum < 20`, but because `acidBaseSum > 0` catches *all* cases where acid/base is present, it never reaches those checks.
**Learning:** When classifying states based on multiple interacting variables (like concentrations), evaluate the dominant feature across *all* components rather than returning early on the first non-zero component. Condition blocks should be ordered by their specificity or check for dominance rather than mere presence.
