## 2023-10-25 - Fix cumulative rounding producing negative chemical concentration values
**Bug:** Cumulative rounding of chemical concentrations from their percentage of the total mixture produced negative remainder percentages (i.e. `nc < 0`), leading to invalid database hashes or inaccurate score computations in both the server and client codebase.
**Root Cause:** `chem_a`, `chem_b`, and `chem_i` values were independently rounded up using `Math.round((chem / total) * 100)`, causing their sum to sometimes exceed 100%. `chem_c`, generated dynamically as `100 - na - nb - ni`, received the entire negative difference. In the server backend, this was partially fixed but was done via subtracting the entire mathematical deficit from a single component, unbalancing the combination. In the frontend, it was left unchecked, leading to negative values being passed into hashing algorithms.
**Learning:** Cumulative rounding constraints that mandate an exact sum must be balanced iteratively. When one array of elements generates a remainder that violates boundaries, it should be distributed logically (iteratively) over the set's components to ensure precision constraints and mathematical validity.
