## 2026-06-19 - Inconsistent Multiplier Mapping in Catalyst and Indicator ID Logic
**Bug:** The catalyst and indicator presence thresholds were adding incorrect multiplier values to the `reaction_id` in `server/controllers/resultController.js`, causing it to mismatch the expected values generated by `server/utils/reactionHash.js` and the database migration scripts.
**Root Cause:** The parameters `i` (indicator) and `c` (catalyst) in the `computeReactionId` function signature in `server/controllers/resultController.js` had their mapping logic inverted. `i` was adding `100` and `c` was adding `1000`, when it should have been the other way around.
**Learning:** Always ensure constants or hash algorithms (like `computeReactionId`) are imported from a single, shared source of truth (like `utils/reactionHash.js`) rather than being duplicated in controllers, to prevent drifting logic bugs between the backend API and the database layer.
