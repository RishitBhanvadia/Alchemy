## 2025-05-24 - Virtual Science Labs Market Gap
**Market Insight:** Top competitors (Labster, PraxiLabs) provide strong educational scaffolding like embedded lab manuals and safety protocols. They never just provide a sandbox without context or real-world lab procedures.
**Codebase Match:** Alchemistry's `Lab3D` provides a visually stunning sandbox but lacks context ("Drag and pour..."). The `history` page only provides a visual log, missing data export features essential for lab reports.
**Opportunity:** Add embedded instructions/lab manuals, chemical tooltips, and CSV export for history to bridge the gap between a visual sandbox and an educational tool. These are high-impact, achievable improvements using existing stores and UI components.
