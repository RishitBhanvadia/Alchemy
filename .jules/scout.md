## 2024-06-02 - Market Insight: Lab Simulation Gamification
**Market Insight:** Top virtual lab competitors (Labster, Praxilabs) heavily lean into gamification (achievements, badges, leaderboards) to maintain student engagement in an educational setting.
**Codebase Match:** The app has a basic points/score system and tracks experiment history via `logs` and `assignments` (StudentDashboard.jsx), but lacks visible gamified milestones (badges/achievements).
**Opportunity:** We can implement a badge system (e.g., "First Reaction", "Master Mixer") leveraging the existing Supabase experiment history logs, making the dashboard more rewarding.
