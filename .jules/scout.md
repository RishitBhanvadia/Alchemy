## 2024-03-24 - Contextual Tools in Virtual Chemistry Labs
**Market Insight:** Top virtual chemistry simulators like PraxiLabs differentiate themselves by integrating contextual learning aids directly into the 3D lab environment, rather than just providing a visual simulator. Key features include built-in lab manuals and tools for calculations and data export.
**Codebase Match:** Alchemistry currently has strong 3D visualization and basic dashboard infrastructure, but the primary 3D lab interface (`Lab3D.jsx`) lacks integrated tools for students to reference instructions or perform calculations without leaving the app. The result logs (`history.jsx`) and modal (`ResultModal.jsx`) also lack standard export capabilities.
**Opportunity:** The most impactful enhancements for Alchemistry are adding a toggleable Lab Manual panel to the 3D lab view and enabling CSV export of experiment results. These features will significantly close the gap between a pure simulator and a comprehensive educational tool, requiring relatively low development effort.
