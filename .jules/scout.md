## 2026-04-11 - Integration of Pedagogical Tools with Visual Simulations
**Market Insight:** Top virtual chemistry labs (e.g., Labster, ChemCollective, PhET) don't just simulate reactions visually; they emphasize pedagogical tools like CSV data export for post-lab analysis, interactive safety equipment, and contextual learning prompts. Gamified storylines and interactive simulations can improve student test scores by up to 20%.
**Codebase Match:** Alchemistry currently provides high-quality 3D visuals and a basic result modal, but lacks robust post-lab analysis tools (like CSV export), interactive safety equipment (like goggles/gloves), and real-time sensor readouts (like an on-screen thermometer during exothermic/endothermic reactions).
**Opportunity:** We can build on the existing 3D environment by adding data export capabilities to the `historyStore` and `ResultModal`, implementing a visual thermometer that hooks into the existing `useTemperature.js`, and adding pre-lab safety checks.
