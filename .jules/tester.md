## 2024-05-17 - authStore test setup
**Gap:** The critical `authStore.js` file, which handles session logic and user profile creation, was completely untested (1.8% coverage).
**Learning:** Testing dynamic store imports used in the logout flow requires intercepting the `import()` calls to prevent unhandled rejections or false positives. Mocking `window.location` in a JSDOM environment requires overriding the property descriptor using `Object.defineProperty` since it is non-configurable.
**Pattern:** For `window.location` mocks, use `Object.defineProperty(window, 'location', { value: ... })` instead of `delete window.location`. For dynamic imports in same-level directories, strictly double check relative paths in `vi.mock` (e.g., `vi.mock('../labStore')` rather than `./labStore`) so that Vitest successfully intercepts the runtime `import('./labStore')` calls within the tested module.

## 2024-05-17 - CI Failure (Node.js 20 & Linting)
**Gap:** The build check and test (18.x) check in CI failed because GitHub Actions on `ubuntu-24.04` warns that Node.js 20 actions are deprecated, but more importantly, many ESLint errors were failing the build, including unused variables, invalid `href` attributes in `<a href="#">` tags, and invalid `role` assignments for tabs. There was also an issue with conditionally rendering a `useState` hook due to early returns.
**Learning:** For anchor links with `#`, we should use `<button type="button">` instead of `<a>` to prevent `jsx-a11y/anchor-is-valid` errors. When using tabs, `role="tablist"` is typically used on the container and `role="tab"` on the children, but when assigning roles explicitly, avoid abstract ARIA roles. `role="radiogroup"` is a valid alternative for tab-like toggle groups. For early returns, ensure `if (isTouchDevice) return null;` is placed *after* all hooks (`useEffect`, `useState`).
**Pattern:** Always run `npm run lint` locally before submitting code to ensure no accessibility or unused variable errors block the CI pipeline. Use `button` for empty links, `radiogroup`/`group` instead of `tabs` in simple toggle setups to satisfy `jsx-a11y/aria-role`, and update `.github/workflows/*.yml` versions from `18` to `20` to satisfy node action deprecations.
