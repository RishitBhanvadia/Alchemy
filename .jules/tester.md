## 2024-05-16 - Add Tests for Authentication Flow (authStore)
**Gap:** The critical `authStore.js` file managing session initialisation, login, and user profile creation/fetching lacked any tests, leaving critical user authentication flows vulnerable to regressions.
**Learning:** Implementing tests for state management stores that heavily rely on external services (like Supabase Auth) is crucial for ensuring the stability of authentication flows. Furthermore, handling and testing edge cases within these stores, such as fallback mechanisms when triggers fail to create initial profiles (e.g. recovering from a missing `profiles` entry), is necessary for providing a seamless user experience.
**Pattern:** Use `vitest` and `vi.mock()` to isolate the state store from its external dependencies (e.g., Supabase SDK). This enables testing various authentication states (e.g., initialized with session, session lost, token refreshed) and simulating API error conditions (e.g., network failure, insert conflict) to ensure the application handles them gracefully.
