## 2025-02-12 - Critical missing auth flow tests
**Gap:** Authentication flows (sign up, login), auth state store (Zustand), and key login components were missing unit tests entirely or had insufficient coverage for their core business rules (like validation, switching tabs, handling correct mock api calls, handling error api responses).
**Learning:** Auth forms are critical entry paths. If these are untested, a regression could lock out all users silently without failing builds. Adding explicit interaction testing over validation rules and mock responses provides an essential safety net.
**Pattern:** For Zustand auth stores interacting with Supabase, deeply mock the Supabase auth client (`getSession`, `onAuthStateChange`, `signOut`) and test the initialized state. For Auth forms, mock `react-hot-toast` and Supabase responses, simulating UI flows such as clicking tab switches, triggering form validation edge cases, and verifying success/error API flows are caught accurately and notify the user via toasts.
