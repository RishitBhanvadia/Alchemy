## 2025-06-25 - Improve Dashboard Test Coverage
**Gap:** The frontend `Dashboard` and Authentication forms (`SignUpForm` and `LoginForm`) lack comprehensive tests, especially for mock dependencies like `supabase` and `react-hot-toast` in error boundary scenarios. The `Dashboard.jsx` handles classroom joining using Supabase, which was missing adequate test coverage for success, invalid code, not logged in, and already a member states.
**Learning:** Testing logic involving dependent asynchronous queries (like checking a `classrooms` table before inserting into a `class_memberships` table) requires nested mock chaining in `supabase.from()`. `react-hot-toast` mock also required specifically assigning `.success` and `.error` methods directly to the mock function instead of inside a `.default` export wrapper to prevent `[vitest] No "default" export is defined on the "react-hot-toast" mock` error.
**Pattern:** Mock `supabase.from` by examining the table argument to return uniquely scoped mock queries and ensure `.single()` resolves with `data` or `error` depending on test scenarios. Ensure `react-hot-toast` mock is configured properly using an inline `vi.mock` factory function resolving `toast` and `default`.
