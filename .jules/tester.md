## 2024-04-28 - Mocking Supabase Method Chains in Zustand Stores
**Gap:** The authentication flow logic (`authStore.js`) which handles critical session initialization, profile fetching, and automatic profile creation on PGRST116 errors had completely missing test coverage.
**Learning:** Mocking external chained APIs (like `supabase.from('profiles').select().eq().single()`) directly inside `vi.mock` factory functions can cause "ReferenceError: Cannot access '...' before initialization" because `vi.mock` is hoisted to the top of the file before local variables exist. The workaround involves returning object literals referencing locally scoped mock functions inside the factory.
**Pattern:** Create simple mock functions (`const selectMock = vi.fn()`), combine them into a chain object (`const mockChain = { select: selectMock, eq: eqMock... }`), apply `.mockReturnValue(mockChain)` to them, return the structured mock in `vi.mock`, and crucially, expose the internal mock references via a property like `__mocks__` to allow tests to arrange returns and assert calls (e.g. `supabase.__mocks__.singleMock.mockResolvedValueOnce(...)`).
