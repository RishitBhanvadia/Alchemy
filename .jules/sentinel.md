## 2025-05-10 - Replaced Insecure Math.random() with crypto.randomInt()
**Vulnerability:** The codebase was using `Math.random()` to generate alphanumeric meeting codes and class codes in `server/controllers/meetingController.js` and `server/controllers/classroomController.js`. `Math.random()` is not a cryptographically secure pseudo-random number generator (CSPRNG), making the generated codes predictable and susceptible to brute-force or guessing attacks if an attacker observes enough output.
**Learning:** Standard library random functions like `Math.random()` should never be used in security-sensitive contexts, such as generating access codes, tokens, or identifiers that grant access to resources (meetings, classrooms).
**Prevention:** Always use a CSPRNG for generating unpredictable values. In Node.js, `crypto.randomInt()` or `crypto.randomBytes()` should be used. Ensure all future code generation logic adheres to this by reviewing PRs for `Math.random()` usage in authorization contexts.
