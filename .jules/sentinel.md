## 2024-05-24 - Secure Random Number Generation for Class Codes
**Vulnerability:** The `generateClassCode` function in `server/controllers/classroomController.js` was using `Math.random()` to generate alphanumeric strings for class codes. This is insecure as `Math.random()` does not produce cryptographically secure pseudorandom numbers, making the generated codes predictable and potentially allowing attackers to guess valid class codes and join classrooms unauthorized.
**Learning:** For any security-sensitive random string generation, such as codes or tokens, a secure PRNG (Pseudorandom Number Generator) like `crypto.randomBytes()` must be used. Additionally, naive conversion methods from bytes to characters like `byte.toString(36)[0]` introduce severe probability bias and should be avoided.
**Prevention:** Always use `window.crypto.getRandomValues()` (in browsers) or `crypto.randomBytes()` (in Node.js) for security-critical values. Convert bytes to an alphanumeric string securely, for instance by mapping bytes against a defined alphanumeric array using modulo arithmetic against the array length (`chars[byte % chars.length]`), to ensure a uniform distribution of characters and avoid predictability.
