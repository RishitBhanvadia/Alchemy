## 2025-02-17 - Express Middleware Misconfigurations (DOS, XSS, CORS)
**Vulnerability:** The Express server used vulnerable middleware configurations: an excessive 50mb limit on `body-parser` (DOS risk), `unsafe-inline` styles in the `helmet` CSP (XSS risk), and a globally permissive `cors` configuration allowing any origin.
**Learning:** These defaults or permissive settings are easy to copy-paste but present immediate risks. For instance, allowing 50mb payloads gives attackers a way to consume server resources and DOS the application, while permissive CORS can lead to unauthorized cross-origin requests. `unsafe-inline` styles allow potential attackers to inject and execute unauthorized CSS, leading to potential data exfiltration or UI redress.
**Prevention:** Always restrict request payloads to the minimum necessary size (e.g., 1mb). Ensure CSP headers restrict inline scripts and styles unless absolutely necessary, and implement a strict whitelist of allowed origins for CORS.
