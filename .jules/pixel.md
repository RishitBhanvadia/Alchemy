## 2024-05-24 - Fix accessibility of range sliders in 3D physics lab
**Problem:** The custom range sliders for chemical concentrations lacked proper semantic `<label>` elements, causing them to fail accessibility checks and preventing screen reader users from understanding what each slider controlled.
**Context:** The app depends heavily on adjusting chemical concentrations via these sliders. If visually impaired users cannot use them, the core value proposition of the app is inaccessible. The visual design used `<div>` and `<span>` elements to group the chemical name and formula, breaking the `<label>` -> `<input>` link.
**Solution:** Replaced the generic wrapper `<div className="label-group">` with a semantic `<label htmlFor="...">` while preserving the existing class names to maintain the exact visual design system. Added matching `id` attributes to each corresponding `<input type="range">`. This fixes `jsx-a11y/label-has-associated-control` ESLint errors without requiring any CSS changes.
