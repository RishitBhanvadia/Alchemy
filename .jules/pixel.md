## 2024-05-22 - Neon Empty State Pattern
**Problem:** The default empty state was plain text, which felt jarring against the high-fidelity glassmorphism UI.
**Context:** In a "virtual lab", users expect immersion. A boring text message breaks the "sci-fi" illusion.
**Solution:** A centered layout with a large, glowing icon (using `drop-shadow` and `--primary-neon`) and a glassmorphism container. This maintains the "holographic" feel even when there is no data.
