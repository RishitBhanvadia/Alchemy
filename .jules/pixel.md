## 2024-05-21 - Standardise Empty States and Fix CI
**Problem:** The ClassroomDetail page displayed unstyled text for empty student rosters and assignment lists, causing visual inconsistency. Additionally, the GitHub CI pipeline was failing due to using an outdated Node.js version (18) which caused issues with `@tailwindcss/oxide` bindings, and there were several ESLint errors including unused imports, invalid `href="#"` attributes on anchor tags, and invalid ARIA roles (`role="student"` instead of `userRole="student"`).
**Context:** Consistent and helpful empty states are critical for a seamless user experience, especially in a teacher dashboard where users need to know how to proceed when lists are empty. Consistent and helpful CI checks are critical for a seamless developer experience.
**Solution:** Replaced manual text messages with the application-wide `EmptyState` component. Updated Node versions in GitHub workflows from 18 to 20. Removed unused imports (`Loader2`, `Check`, `useCallback`). Replaced `href="#"` `<a>` tags with accessible `<button type="button">` elements. Renamed the `role` prop in `RoleCard` to `userRole` to fix ARIA role validation. Removed the early return violation in `CursorFollower.jsx` to adhere to Rules of Hooks.
