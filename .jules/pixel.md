## 2024-05-17 - Improve EmptyState consistency and UI hierarchy
**Problem:** Inconsistent `EmptyState` component usage across the app (StudentDashboard, TeacherDashboard, History). Some pages use custom `.empty-state` wrapper classes with differing paddings and colors instead of relying on the component. The `EmptyState` component itself was missing contextual awareness (lacked dynamic sizing or styling options).
**Context:** Alchemistry's UI relies on glassmorphism and clear visual hierarchy. Empty states are a critical UX pattern when a student hasn't completed an experiment or a teacher hasn't added students. The existing `EmptyState` lacked polish and was overriden inconsistently, leading to jarring layout shifts and poor visual rhythm.
**Solution:** Consolidated `EmptyState` styling, removed redundant wrapper classes in parent components, improved the `EmptyState` component's internal spacing, typography, and button to match the app's established design tokens (e.g., `--color-accent-primary`, `--glass-bg`).
