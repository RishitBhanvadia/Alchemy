## 2024-05-24 - Context-Aware Experiment Status Badge
**Problem:** The 3D Chemistry Laboratory page showed a static text warning ("Mix at least 2 chemicals to start") whenever fewer than 2 chemicals were added. It provided no step-by-step guidance, lacked an empty state prompt, and did not confirm when the user was ready to react. Additionally, the styling (`<p className="note-warn">`) didn't match the glassmorphic aesthetic of the rest of the application.
**Context:** For a primary user flow (running an experiment), users need immediate, contextual feedback about the system's readiness state. Ambiguity causes friction. The app uses a neon/glassmorphism design language where interactive or status elements should feel integrated.
**Solution:** Replaced the static warning with a dynamic `.reaction-status-badge` that tracks the exact number of active chemicals (0, 1, or 2+). It displays corresponding states ("Add chemicals to begin", "Add 1 more chemical to react", "Ready to react") with distinct colors (warning amber vs. success green) and emojis. It uses `aria-live="polite"` and is hidden during the `loading` state to prevent an empty pill box from rendering.
