## 2024-05-15 - Actionable Empty State in History
**Problem:** The history page showed a plain text empty state ("No experiments recorded yet...") with no visual hierarchy or clear call-to-action, causing user friction.
**Context:** For a primary data-viewing page, an empty state is the first impression for new users. It needs to guide them to the core action of the app.
**Solution:** Replaced the plain text with a visually engaging empty state using existing design tokens (neon colors, glass panels) and a primary call-to-action button directing users to the dashboard.
