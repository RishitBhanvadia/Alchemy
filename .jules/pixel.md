## 2024-03-24 - Student Dashboard Accessibility & Contextual Empty States
**Problem:** The primary navigation method for students (Experiment Modules) was implemented using non-accessible `div` elements with an `onClick` handler, making the core flow completely inaccessible to keyboard users. Additionally, the assignments empty state was inconsistent with the rest of the app's visual language.
**Context:** For this application, students must be able to seamlessly access modules like "Titration" and "Organic Chemistry" from the main dashboard. Keyboard accessibility is critical for educational software compliance (WCAG). Moreover, consistent empty states (`EmptyState` component) reduce cognitive load when users have no pending assignments.
**Solution:** Replaced the non-interactive module `div`s with semantic React Router `<Link>` components wrapped in `motion.div`. This provides native focus states (`:focus-visible`) and keyboard operability without compromising the Framer Motion animations. Also standardized the assignments section to use the `EmptyState` component with a `.compact-empty` layout variation to fit the dense dashboard grid.
