## 2024-05-29 - Improve Role Card UX
**Problem:** In the signup form, users are forced to select between "student" and "teacher" roles using role cards. While the cards look okay when selected, they lack accessible keyboard interaction, the labels rely entirely on visual cues with no clear descriptive error focus states, and the overall role selector looks detached from the rest of the form's visual hierarchy.
**Context:** This app heavily relies on role-based access. If users choose the wrong role, their entire dashboard experience changes drastically, leading to high frustration. The role selection process is a crucial step in onboarding.
**Solution:** Refactor RoleCard to use `<button type="button" role="radio">` and the container to use `role="radiogroup"`. Improve the visual feedback with better focus outlines, enhanced colors, and layout consistency. Added error highlighting specifically on the cards themselves to guide the user naturally when a validation error occurs.
