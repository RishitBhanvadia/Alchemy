## 2024-05-24 - Result Visual Hierarchy
**Problem:** In the Titration experiment, the primary user feedback (their final score and result message) was buried inside an instructional `.note-box` container.
**Context:** The user's main job-to-be-done in this app is to complete experiments and see their results. Mixing instructions (notes) with results (primary feedback) causes confusion.
**Solution:** Separated the result message into a distinct, neon-styled `.result-box` to match the app's theme and create a clear visual hierarchy, elevating the experiment outcome above static instructions.
