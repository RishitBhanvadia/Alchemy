## 2024-05-18 - Improve Empty State UX in History
**Problem:** The History page shows a plain text empty state 'No experiments recorded yet...' which looks unfinished compared to the highly stylized glassmorphism UI.
**Context:** As a new student logging in, reviewing history is a key flow. A visually appealing empty state acts as onboarding.
**Solution:** Designed an empty state container with an icon, stylized text, and a call-to-action button to guide users back to the lab, matching the existing design system.
