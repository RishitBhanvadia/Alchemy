## 2024-05-24 - Lazy-load heavy 3D components (`@react-three/drei`)
**Bottleneck:** Eager imports of heavy 3D libraries (like `CanvasContainer`, `FloatingMolecule`, and `OrbitControls` from `@react-three/drei`) in root or layout components (`client/src/pages/Landing.jsx` and `client/src/pages/lab.jsx`) caused massive initial JS payload bundle sizes (e.g. `Landing` was 18.14 kB before gzip and 3D assets bloated it further).
**Impact:** `Landing` JS bundle reduced to 1.30 kB (0.65 kB gzipped). Heavy 3D assets are now dynamically split into separate chunks only loaded when rendered. Initial page load and parsing time of main application is significantly faster.
**Learning:** To prevent massive initial JS payloads, heavy 3D rendering libraries and components must be lazy-loaded using `React.lazy` and `Suspense` rather than imported eagerly. When lazy-loading named exports from heavy libraries (like `OrbitControls`), use a promise chain to map the export to the default property: `lazy(() => import('@react-three/drei').then(module => ({ default: module.OrbitControls })))`.
