## 2026-04-14 - Lazy load heavy UI panels in Lab3D
**Bottleneck:** The `AiTutorPanel` and `ResultModal` components in `Lab3D.jsx` were imported synchronously, leading to a larger initial bundle (`Lab3D` chunk was 16.05 KB gzip: 5.53 KB). These are heavy interactive panels that are only shown when the user clicks the AI tutor button or finishes an experiment.
**Impact:** Initial load time is reduced. The `Lab3D` chunk size was reduced from 16.05 KB to 11.20 KB. `AiTutorPanel` and `ResultModal` are now split into their own chunks (3.44 KB and 2.45 KB respectively) which are fetched on demand.
**Learning:** To lazily load components while preserving Framer Motion `AnimatePresence` exit animations, do not conditionally unmount the `Suspense` boundary based on their active state (e.g., `isOpen`). Instead, use a local state variable (like `hasOpened`) to permanently mount the `Suspense` boundary after the first user interaction, passing the `isOpen` prop into the lazily loaded component.
