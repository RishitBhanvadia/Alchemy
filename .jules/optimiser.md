## 2024-05-18 - High-Frequency Event Optimization (mousemove)
**Bottleneck:** High-frequency events like `mousemove` firing dozens of times per second and triggering React state updates (`useState`). In `CursorFollower.jsx`, updating cursor coordinates via state caused the entire component to re-render constantly, consuming significant CPU resources.
**Impact:** Eliminating re-renders for every mouse movement provides a much smoother UI experience, directly impacting perceived performance across the entire application (since the cursor follower is mounted globally in `App.jsx`).
**Learning:** For components that strictly need to track and update visual coordinates on high-frequency events, bypass React's render cycle completely. Use `useRef` to store references to the DOM elements and directly mutate their inline styles (e.g., `elementRef.current.style.left = ...`) inside the event listener. If `transform` is already used for other positioning (like centering `-50%, -50%` in CSS), stick to updating `style.left` and `style.top`.
