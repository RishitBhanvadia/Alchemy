## 2024-05-13 - Optimize CursorFollower Performance using useRef
**Bottleneck:** The `CursorFollower` component was using `useState` to track the `x` and `y` coordinates of the mouse. Since `mousemove` is a high-frequency event, dispatching state updates on every pixel movement caused severe performance degradation by triggering full React component re-renders constantly while the user was moving their mouse.
**Impact:** Eliminates continuous React re-renders during mouse movement, leading to significantly smoother animations and avoiding potential main-thread blocking, which substantially improves user-perceived performance and site responsiveness.
**Learning:** For tracking high-frequency events like `mousemove` or `scroll` for purely visual updates, relying on React's `useState` is a major anti-pattern due to the overhead of React's reconciliation and render cycle. Using `useRef` to hold direct references to DOM elements and manually updating their inline styles and class lists provides maximum performance by bypassing the React lifecycle completely.
