## 2024-05-14 - Direct DOM Mutation for High-Frequency Events
**Bottleneck:** The `CursorFollower` component was using React `useState` to track the user's cursor position during `mousemove` events. This caused the component to re-render constantly (at 60+ FPS) whenever the mouse was moving, leading to severe performance degradation and high CPU usage across the application, especially since the cursor is globally present.
**Impact:** Significantly reduced main thread blocking and React render cycle overhead. The `CursorFollower` component now only re-renders when hover, click, or visibility states change, rather than on every single pixel movement. This translates to a smoother UI and more responsive interactive elements elsewhere on the page.
**Learning:** For high-frequency events like `mousemove` that only require visual updates (like moving a custom cursor or dragging an element), bypassing React's state management and using `useRef` for direct DOM manipulation (`ref.current.style.left = ...`) is a critical pattern to prevent application-wide render thrashing. React state should be reserved for structural UI changes.
