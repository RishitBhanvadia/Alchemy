## 2025-06-01 - DOM Mutating Refs vs React State for High-Frequency Events
**Bottleneck:** The `CursorFollower` component historically stored the mouse `x` and `y` position in React state (`setPosition`), causing it to constantly re-render on every single `mousemove` event. Because `CursorFollower` is rendered near the root (`App.jsx`), this triggered excessive re-renders across the entire React component tree.
**Impact:** Converting the mouse coordinate tracking to use `useRef` and direct DOM mutation (`ref.current.style.left`) entirely eliminated React state updates for mouse movements, preventing continuous application-wide re-renders and drastically improving overall runtime performance.
**Learning:** For extremely high-frequency events like `mousemove` or `scroll` that strictly control visual presentation (like custom cursors), mixing React state for CSS classes (like `hovering` and `clicking`) with manual DOM mutations for positioning is the optimal pattern to avoid severe performance bottlenecks.
