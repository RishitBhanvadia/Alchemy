## 2025-04-13 - Lazy Loading Heavy Modal Components for Lab3D
**Bottleneck:** The `AiTutorPanel` and `ResultModal` components were being imported statically into `Lab3D.jsx`, resulting in their code being included in the main `Lab3D` chunk even if they are never opened by the user, slowing down initial load time.
**Impact:** Initial chunk size for `Lab3D.js` dropped from ~16KB to ~11.2KB (a ~30% reduction in this specific chunk's JS, with their CSS properly split), creating smaller isolated chunks of ~3.4KB and ~2.4KB respectively that load only on-demand.
**Learning:** Using React's `lazy` and `Suspense` allows us to lazily load interactive modals. However, when lazy-loading modals that use Framer Motion's `AnimatePresence`, simply conditionally rendering the element itself (like `isOpen && <Modal />`) breaks the exit animation since the component unmounts instantly. Instead, we render the `Suspense` boundary permanently after the first interaction using a custom `hasOpened` state to preserve exit animations.
