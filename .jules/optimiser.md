## 2025-03-02 - Eliminate CursorFollower React state re-renders
**Bottleneck:** The `CursorFollower` component was triggering a `setState` call (`setPosition`) on every single `mousemove` event across the entire application. This caused continuous Virtual DOM diffing and re-renders for the application's root/layout whenever the mouse moved.
**Impact:** Eliminated high-frequency React render cycles (60+ per second during movement). Mouse movement is now handled entirely through direct DOM mutation (`useRef` + `style` and `classList`), making cursor tracking completely independent of React's rendering pipeline and significantly improving perceived UI smoothness, especially on lower-end devices.
**Learning:** For high-frequency DOM updates bound to rapid window/document events (like `mousemove` or `scroll`), React state is too slow and causes unnecessary rendering overhead. Instead, use `useRef` to maintain references to the DOM nodes and update their properties (e.g., `style.left`, `classList`) directly inside the event listener. This effectively bypasses the Virtual DOM diffing process while retaining the declarative component structure.
