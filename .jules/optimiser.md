## 2025-02-27 - Lazy Loading Heavy Chart Component
**Bottleneck:** The `TeacherDashboard.jsx` was importing `StudentAnalyticsChart` directly, which in turn imported Recharts, a very large data visualization library. This caused the main javascript bundle to be unnecessarily large (> 1MB initial load depending on other dependencies), slowing down the initial page load time for users.
**Impact:** Using React.lazy to code split `StudentAnalyticsChart` reduced the initial JavaScript payload by 108KB for the `TeacherDashboard.jsx` component, moving Recharts out of the main critical path bundle.
**Learning:** In Alchemistry React components where styling is defined as a `const styles = { ... }` at the bottom of the file, avoid referencing `styles` in newly added structural wrappers like `React.Suspense` fallbacks. Since `styles` is a `const` initialized at the bottom of the file, referencing it higher up in the component tree causes a `ReferenceError: Cannot access 'styles' before initialization` which crashes the page rendering. Use inline styles or existing components (e.g., `<SkeletonBlock />`) to prevent variable hoisting issues and undefined reference errors.
