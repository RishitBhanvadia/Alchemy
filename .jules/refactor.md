## 2024-05-24 - Fix stale closure and missing dependency in useEffect
**Before:** `calculateStats` was defined outside `useEffect` but used inside it. This caused a `react-hooks/exhaustive-deps` warning. Furthermore, `experiments` state was being set but never used in the component, causing a `no-unused-vars` error. During the first attempt to fix the warning, moving `calculateStats` inside `useEffect` caused `badges` to be added to the dependency array, triggering an infinite loop since `setBadges` creates a new array reference.
**Issue:** ESLint warnings about missing dependencies in `useEffect` and unused state variables. When moving functions inside `useEffect`, accessing state directly from the component scope adds it to the dependency array. Updating that state inside the same effect creates an infinite render cycle.
**Learning:** For helper functions only used inside a single `useEffect`, moving the function definition inside the `useEffect` resolves dependency array warnings. However, when those functions update state that they also read, you MUST use functional state updates (e.g., `setBadges(prev => ...)`). This allows you to safely omit the state variable from the dependency array, avoiding infinite render loops and unnecessary API calls.
