## 2024-05-24 - Extracting Components to Reduce Render Complexity
**Before:** `client/src/pages/history.jsx` contained a single, monolithic `History` component (over 100 lines) that handled data fetching, date formatting, and rendering three distinct visual states (Loading, Empty, and a complex Table) via deeply nested ternary operators.
**Issue:** The main component was difficult to read due to mixed abstraction levels (fetching logic alongside nested HTML tables). Additionally, the `formatDate` utility function was unnecessarily redefined on every render cycle.
**Learning:** Extracting conditional rendering blocks into purely functional, stateless sub-components (`LoadingState`, `EmptyState`, and `HistoryTable`) significantly improves the readability of the main component by clearly defining its rendering states without the visual noise of the underlying HTML structure. Moving utility functions (`formatDate`) outside the component scope prevents unnecessary re-allocations during state updates.
